# ipv4-toolkit

零依赖的 IPv4 / CIDR 计算工具，库 + CLI 一体。纯函数实现，Node 18+，`npm install` 只为拿 `bin`，跑测试不需要装任何东西。

## 安装 / 使用

```bash
npm install -g ipv4-toolkit   # 之后可直接用 ipv4 命令
# 或者不装，直接跑：
node bin/ipv4.js --help
```

## CLI

**网段信息**

```bash
$ ipv4 info 10.1.2.3/22
CIDR            10.1.0.0/22
网络地址        10.1.0.0
广播地址        10.1.3.255
子网掩码        255.255.252.0 (/22)
地址总数        1024
可用主机        1022
可用区间        10.1.0.1 ~ 10.1.3.254
私有地址        是
```

**子网切分**

```bash
$ ipv4 split 192.168.0.0/24 26
192.168.0.0/24 切分为 4 个 /26：
  192.168.0.0/26      64 个地址
  192.168.0.64/26     64 个地址
  192.168.0.128/26    64 个地址
  192.168.0.192/26    64 个地址
```

**归属判断**（命中退出码 0，未命中退出码 1，参数错误 2）

```bash
$ ipv4 contains 10.0.0.0/8 10.1.2.3
10.1.2.3 属于 10.0.0.0/8
```

## 作为库使用

```js
import { describe, split, contains, parseCidr, hostCount } from 'ipv4-toolkit';

describe('172.16.5.9/20');
// { cidr: '172.16.0.0/20', network: '172.16.0.0', broadcast: '172.16.15.255',
//   mask: '255.255.240.0', prefix: 20, size: 4096, hosts: 4094,
//   first: '172.16.0.1', last: '172.16.15.254', private: true }

split('10.0.0.0/16', 20).map(b => b.cidr);
// [ '10.0.0.0/20', '10.0.16.0/20', ... 共 16 块 ]

contains('192.168.1.0/24', '192.168.1.255');  // true
```

## 边界约定

| 前缀 | 地址总数 | 可用主机 | 说明 |
| --- | --- | --- | --- |
| /0 | 2^32 | 2^32-2 | 网络号与广播地址不可用 |
| /24 | 256 | 254 | 常规网段 |
| /30 | 4 | 2 | 点对点链路常见 |
| /31 | 2 | 2 | 按 RFC 3021，两端都可用 |
| /32 | 1 | 1 | 单主机路由 |

- `split` 默认上限 65536 块，超出会报错，需要显式放宽 `limit`，避免一次打印几百万行。
- 输入里的 IP 段不接受前导零（`01` 视为非法，避免八进制歧义）。
